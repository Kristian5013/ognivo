- [high] Claude Code (v2.1.312, 2026-10-27) assembles its prompt from 500+ conditional strings. /context breakdowns show 3.8-6.2K tokens of system prompt plus 11.4-21K tokens of built-in tool schemas before any work (some configs reach 35K + 21K). TodoWrite's description is 2,037 tokens, the Agent usage notes 2,040, and the Bash git-commit section 1,477.
  evidence: https://github.com/Piebald-AI/claude-code-system-prompts (README, v2.1.312, Oct 27 2026); https://www.jdhodges.com/blog/claude-code-context-slash-command-token-usage/ (2026-03-22); https://wmedia.es/en/tips/claude-code-context-command-token-usage (2026-02-07); https://github.com/anthropics/claude-code/issues/45719 (2026-04-09)
- [high] Claude Code's tool set (Oct 2026): Agent (background subagents, forks, teams), Bash, Read, Edit (exact old_string/new_string, no regex or fuzzy matching, read-before-edit, replace_all), Write, LSP, Monitor, Task* tools (TodoWrite disabled by default), Enter/ExitPlanMode, ToolSearch (deferred MCP and system tools), WebFetch/WebSearch, Skill and worktree tools. On macOS/Linux/WSL, Glob and Grep are removed by default and searching goes through Bash with embedded bfs/ugrep.
  evidence: https://code.claude.com/docs/en/tools-reference
- [high] Claude Code's Bash output policy: successful output goes inline up to about 30,000 chars; beyond that the model gets a saved-file path plus a preview of up to 2,000 chars. Failures get a head+tail excerpt of up to 10,000 chars. Default timeout is 2 min (max 10); a command that hits its timeout is auto-backgrounded. Exit code 1 counts as benign only for grep/rg/find/diff/test/git diff. A cgroup memory cap is optional. The cwd persists inside the project; env vars do not persist.
  evidence: https://code.claude.com/docs/en/tools-reference (Bash tool behavior)
- [high] Claude Code checkpoints snapshot files edited by its file tools before each prompt (the 100 most recent checkpoints are kept); /rewind restores code, conversation or both. Files changed only by Bash are not tracked, and most subagent edits are not restored.
  evidence: https://code.claude.com/docs/en/checkpointing
- [high] Claude Code's sandbox covers shell commands only: Seatbelt on macOS, bubblewrap + socat on Linux/WSL2 (via @anthropic-ai/sandbox-runtime), off by default, with network access through a local proxy and a domain allowlist. File tools, MCP servers and hooks run outside it. The permission system has 7 modes, including an ML-classifier auto mode, motivated by the finding that users approve 93% of permission prompts.
  evidence: https://code.claude.com/docs/en/sandboxing; https://arxiv.org/html/2604.14228v2 (Dive into Claude Code, 2026-07-02)
- [high] Claude Code runs against llama.cpp through the Anthropic-compatible /v1/messages endpoint.   evidence: https://unsloth.ai/docs/basics/claude-code (2026-10-15); https://llms-explorer.com/tree/unsloth-studio-as-an-anthropic-compatible-endpoi/; https://docs.vllm.cc/en/latest/serving/integrations/claude_code/; local tools/server/README.md:10,1622-1650
- [high] Codex CLI (rust-v0.166.0-alpha.6, 2026-10-29) is a Rust workspace of 150+ crates (core, protocol, app-server, app-server-protocol, exec, exec-server, tui (Ratatui), codex-mcp/rmcp-client, apply-patch, execpolicy (Starlark), linux-sandbox, bwrap, hooks, rollout, ollama, lmstudio...). - [medium] Codex is sandbox-first: a Starlark exec policy (prefix_rule/network_rule/host_executable, starts empty) -> permission profiles -> OS backend (Linux: bubblewrap preferred, legacy Landlock path, seccomp) -> MITM network proxy. - [medium] OpenCode adapts per model. It rebuilds the tool set for every request (GPT-family models get apply_patch instead of edit+write). It layers per-family system-prompt plugins (anthropic 300 B, gpt 2.5 KB, kimi 8.7 KB, meta 7.8 KB) on a ~756-byte base prompt. Its edit tool tries an exact match, then ignores typographic quote/dash/space variants, then trailing whitespace. In v1.x, edit/write appended LSP errors to the tool result (errors only, at most 20 per file); the v2 core has 'TODO: Add LSP notification and diagnostics'. Tools default into 'CodeMode', a JS-like interpreter that can only call tools.

- [high] Reasoning-retention rules for the two reference models are the same: drop prior-turn chain-of-thought after a final answer, but keep it between tool calls inside one turn (OpenAI harmony/gpt-oss; Google Gemma 4).
